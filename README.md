# Netflix Together — unofficial student concept

A single-file, no-dependency clickable prototype for a university Strategy project.
**Not affiliated with Netflix.** All film titles are fictional.

## Run
Open `index.html` in any modern browser. It works offline; nothing is synced or stored.

## Flow
Landing → Who's watching (profiles, guests) → Mood (genres, time, no-horror) →
Top 3 shortlist → private voting in turns with hand-off screens → match, or
options when there is no overlap (relax filters, new shortlist, go with the closest).

## Posters
Drop optional artwork into `images/` named `<film-id>.jpg`, e.g.
`images/midnight-detour.jpg`. If a file is missing, a CSS gradient poster is shown.
Featured ids: `midnight-detour`, `weekend-plan`, `city-of-chances`, `orbit-nine`,
`glass-city`, `seaside-summer`. Extra ids: `iron-pursuit`, `final-whistle`, `fast-break`,
`heartline`, `quiet-signal`, `long-crossing`, `hollow-house`, `last-floor`, `lucky-strike`.
`midnight-detour.jpg` is also used as the landing hero and mood-screen art.
